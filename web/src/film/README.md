# The film on the first screen

`film.js` is the drawing code of It's launch film: every frame of the film is a function of its time, drawn on a canvas, and the site's first screen plays the stretches of it that show one thing It can be. It is made from the film's own source, which is kept with the film and not in this repository, so it is not edited here: a change to a picture is a change to the film, and the file is then made again and copied in whole.

`film.d.ts` says what the site uses of it, and `play.ts` is what puts a stretch of it on the screen. The typefaces it draws in are in `web/public/fonts`, and `THIRD_PARTY_NOTICES.md` says whose they are.
