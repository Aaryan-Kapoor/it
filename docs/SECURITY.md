# Security policy

## Reporting a security problem

If you find a way past something that It says it keeps closed, or a way to make It give up what it holds, report it privately and not in an issue or a pull request, which everyone can read. On GitHub, open this repository's Security tab and choose "Report a vulnerability". What you write there is seen only by the people who look after the repository.

## What It protects

[What It protects, and what it does not](what-it-protects.md) says what It keeps closed and, in full, where that stops. It is made for one person, on their own computer and their home network, and it is not made for the public internet.
