These are the faces the tour's first page is set in. packages/cli/tour.mjs sets
each into the page, so that the page needs nothing from anywhere else.

display-700, display-800, text-400, text-500, text-600: Inter and Inter
Display, by Rasmus Andersson. SIL Open Font License 1.1. Subsets of the site's
own files in web/public/fonts, of the Latin letters and signs the page uses.

caveat-600: Caveat SemiBold, by the Caveat Project Authors. SIL Open Font
License 1.1. A subset, of the Latin letters and signs the page writes in it.

The chessboard draws its pieces as outlines of its own, and carries no face for them.
The words of each license are in THIRD_PARTY_NOTICES.md.
